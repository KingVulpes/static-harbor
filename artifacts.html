Artifacts

Eight pieces that pitch Static Harbor, each with its concept, execution and software.

Artifact 1 of 8

Key Art

Concept
The hero image that sells the game in one frame: the tidal-control station at 2AM, floodlights cutting through fog, something rising in the water below.
Execution
Composited from painted environment layers, a 3D-style depth pass for lighting, and colour grading to the neon-cyan / hot-pink palette. Layered PSD shows background, midground, lighting and effects groups.
Software
Photoshop

Artifact 2 of 8

Logo & Character Sheet

Concept
The Static Harbor logo plus turnarounds of the Tidewalkers, the harbor's enemies, each with a distinct silhouette so the player can recognise them from the camera feed alone.
Execution
Vector construction with the pen tool and shape builder, a limited five-colour palette, and a separate layer per character view. Exported as SVG and PNG.
Software
Illustrator

Artifact 3 of 8

Game Design Pitch Document

Open PDF

Concept
A multi-page pitch: premise, core loop, night-by-night progression, enemy behaviour, art direction and target audience.
Execution
Built on a master-page grid with paragraph and character styles, linked images and a table of contents. Exported to interactive PDF.
Software
InDesign

Artifact 4 of 8

Animated Enemy & UI Sequence

If no video appears, add media/04-animation.mp4

Concept
A looping animation of the camera-feed UI glitching as a Tidewalker approaches, showing the tension the player manages.
Execution
Frame-by-frame and tweened animation on a layered timeline using symbols and nested movie clips for the HUD. Exported as MP4.
Software
Animate

Artifact 5 of 8

Teaser Trailer

If no video appears, add media/05-trailer.mp4

Concept
A 45-second teaser that follows one night from 12AM to 6AM, ending on the dawn bell.
Execution
Edited in Premiere with J/L cuts, speed ramps, colour grading with Lumetri and a mixed audio bus; uses footage from the prototype plus Artifacts 1, 4 and 6.
Software
Premiere, Audacity

Artifact 6 of 8

Ambient Audio & SFX Mix

If no player appears, add media/06-audio.mp3

Concept
The sound of the station: tide hum, creaking steel, sonar pings, radio static and the Tidewalker audio cues that warn the player before it is too late.
Execution
Layered recorded and synthesised sounds, noise reduction, EQ, reverb and compression; multi-track project with labelled tracks. Exported as MP3.
Software
Audacity

Artifact 7 of 8

Character & UI Mockup

Concept
A full in-game screen mockup: camera monitor, power meter, clock and floodgate controls.
Execution
Smart objects and layer styles for the HUD, with a pseudo-3D station background. Layer comps show each game state.
Software
Photoshop

Poster / Icon Set
